# フラッシュモブ動画（ツッコミ前フリ用）

縦型ショート動画（1080×1920 / 30fps / 効果音付き）を 2 本、Python で生成します。
ツッコミは撮影側で入れる前提なので、どちらも最後に数秒間の「間」を残して終わります。

| ファイル | 長さ | 内容 | ツッコミ（撮影側） |
|---|---|---|---|
| `video1_formation.mp4` | 約19秒 | 結婚式の余興の振付会議。◯（＝人）を「これが田中さん（新郎の友人代表）」と 1 人ずつ紹介しながら配置 → どんどん加速し、テロップの肩書きも「新郎の上司」→「受付の人」→「司会者」→「ご近所の方」とエスカレート → 右上の配置人数が 150 人に → 「以上、150名で踊ります！（招待客リストより）」 | 参列者全員参加させるんか！ |
| `video2_ginkgo.mp4` | 約16秒 | ピクトグラム 3 人が「東大のイチョウマーク作ります」→ 腕と胴が伸びて脚が縮む → 関節が逆に曲がる（ボキッ）→ しなって巻きつき、2 人が葉 2 枚、1 人が逆立ちで茎に →「完成！」「※関節は考慮していません」（体は分裂しません） | 無理やん！ |

## 名前・肩書きの差し替え（動画 1）

`video1_formation.py` の先頭にあります。

- `NAMED`: 名前付きで紹介する人の `("名前", "肩書き")` の並び。先頭の `SLOW`（4）人はゆっくり、それ以降は加速しながら紹介します。今入っている名前は仮です。
- `CROWD_ROLES`: 名前のない人のテロップ。`(何人目まで, "肩書き")` の形です。
- `TOTAL`: 総人数（150）

## 再生成

```bash
pip install pillow numpy imageio imageio-ffmpeg
python3 video1_formation.py                   # → video1_formation.mp4
python3 video2_ginkgo.py                      # → video2_ginkgo.mp4
python3 video1_formation.py --tsukkomi        # 動画1の最後に文字のツッコミ演出も入れる場合
python3 video1_formation.py out.mp4 --preview # 確認用の静止画 PNG も書き出す
```

日本語フォントは IPA ゴシックを使っています（パスは `common.py` の `FONT_PATHS` で変更できます）。
