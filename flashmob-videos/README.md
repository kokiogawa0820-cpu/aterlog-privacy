# フラッシュモブ動画（ツッコミ前フリ用）

横長 16:9 の動画（1920×1080 / 30fps / 効果音付き）を Python で生成します。
ツッコミは撮影側で入れる前提なので、どちらも最後に数秒間の「間」を残して終わります。

| ファイル | 長さ | 内容 | ツッコミ（撮影側） |
|---|---|---|---|
| `video1_formation.mp4` | 約19秒 | 結婚式の余興の振付会議。◯（＝人）を「これが田中さん（新郎の友人代表）」と 1 人ずつ紹介しながら配置 → どんどん加速し、テロップの肩書きも「新郎の上司」→「受付の人」→「司会者」→「ご近所の方」とエスカレート → 右上の配置人数が 150 人に → 「以上、150名で踊ります！（招待客リストより）」 | 参列者全員参加させるんか！ |
| `video2_ginkgo.mp4` | 約21秒 | 何を作るかは最後まで伏せたまま、ピクトグラム 3 人の動きを淡々とテロップで説明（「3人で1つの形を作ります」→「両手を上げます」→「それぞれポーズをとります」→「腕と胴を伸ばし脚を縮めます」→「関節を逆に曲げます」→「しならせて巻きつけます」）→ 形が完成してから、ゆっくり色が付くのと同時に右側に東大マーク（「東京大学」の文字付き）が浮き出て「東京大学のイチョウマークです」（体は分裂しません。効果音は手順ごとの控えめな音だけ） | 無理やん！ |
| `video2_ginkgo_long.mp4` | 約29秒 | 動画 2 の長い版。「片足で立ちます」「体を横に倒します」の普通の動きと、「腕を少し伸ばします」「体をやわらかくします」のすこーーーしだけ変な動きを挟んでから伸びるパートへ | 無理やん！ |

## 名前・肩書きの差し替え（動画 1）

`video1_formation.py` の先頭にあります。

- `NAMED`: 名前付きで紹介する人の `("名前", "肩書き")` の並び。先頭の `SLOW`（4）人はゆっくり、それ以降は加速しながら紹介します。今入っている名前は仮です。
- `CROWD_ROLES`: 名前のない人のテロップ。`(何人目まで, "肩書き")` の形です。
- `TOTAL`: 総人数（150）

## 再生成

```bash
pip install pillow numpy imageio imageio-ffmpeg
python3 video1_formation.py                   # → video1_formation.mp4
python3 video2_ginkgo.py                      # → video2_ginkgo.mp4
python3 video2_ginkgo.py --long               # → video2_ginkgo_long.mp4（長い版）
python3 video1_formation.py --tsukkomi        # 動画1の最後に文字のツッコミ演出も入れる場合
python3 video1_formation.py out.mp4 --preview # 確認用の静止画 PNG も書き出す
```

日本語フォントは IPA ゴシックを使っています（パスは `common.py` の `FONT_PATHS` で変更できます）。

## 東大のマークについて（動画 2）

- `assets/utokyo_mark.png`（マークのみ）と `assets/utokyo_logo.png`（下に「東京大学」の文字付き。右側に出すもの）は、いただいたマーク画像を `trace_mark.py` で色ごとに塗り直して高解像度にしたものです。人がなぞる形（`video2_ginkgo.py` の `pose_yellow` / `pose_blue` / `pose_ring`）も、この画像の座標に合わせてあります。
- 別の画像から作り直すときは `python3 trace_mark.py 画像.jpg 中心x 中心y 半径` を実行します。
- 東京大学のマークは大学の登録商標です。公開する範囲や使い方には気をつけてください（このリポジトリが公開リポジトリの場合、画像もそのまま公開されます）。
